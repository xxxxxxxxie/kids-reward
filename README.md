# 🌟 超能力积分 - 儿童成长激励App

一个专为家长设计的儿童行为激励应用，通过正向积分机制帮助孩子养成良好习惯。

## ✨ 核心特性

### 🎯 功能亮点
- **拖拽加分**：将成就卡片拖入积分池即可加分，操作简单直观
- **卡片系统**：可自定义卡片名称、图标、分值和颜色主题
- **积分管理**：实时显示总积分，支持兑换扣除并记录备注
- **历史记录**：完整的加分和兑换记录，方便回顾
- **精美动画**：加分时的星星特效和卡片动画，增强趣味性
- **离线可用**：所有数据保存在本地，无需联网

### 🎨 设计特色
- 🧡 温暖的橙色主题，活泼不刺眼
- 📱 完美适配华为Mate60屏幕
- 🌈 6种卡片颜色主题可选
- ✨ 流畅的拖拽交互和动画效果
- 🎮 游戏化的激励机制

## 🎮 使用指南

### 1️⃣ 添加卡片
- 点击右上角 "＋ 新建卡片"
- 选择表情、输入名称、设置分值
- 选择喜欢的颜色主题
- 点击创建

### 2️⃣ 加分操作
- 用手指按住卡片
- 拖动到橙色虚线区域
- 松手即可加分
- 享受星星特效 ✨

### 3️⃣ 使用积分
- 点击 "- 使用积分"
- 输入扣除分值
- 填写兑换备注（如"换了一个玩具"）
- 确认兑换

### 4️⃣ 查看记录
- 向下滚动查看所有加分和兑换历史
- 每条记录包含时间、内容和分值

## 🔧 自定义修改

### 修改默认卡片
编辑 `app.js` 中的初始化数据：
```javascript
if (!cards.length) {
  cards = [
    { id: 1, emoji: '🏃', name: '晨跑锻炼', points: 15, theme: 'theme-orange' },
    // 添加或修改这里的卡片
  ];
}
```

### 修改颜色主题
编辑 `styles.css` 中的 CSS 变量：
```css
:root {
  --bg: #FFF8F0;        /* 背景色 */
  --pool-bg: #FFF3E0;   /* 积分池背景 */
}

.header {
  background: linear-gradient(135deg, #FF9A3C 0%, #FFB347 50%, #FF7043 100%);
  /* 修改顶部渐变色 */
}
```

### 添加更多表情
编辑 `app.js` 中的表情数组：
```javascript
const EMOJIS = [
  '🏃','💪','📚','🧮','📖',
  // 在这里添加更多表情
];
```

### 修改字体大小（华为Mate60优化）
编辑 `styles.css`：
```css
.app-title { font-size: 24px; }  /* 增大标题 */
.score-num { font-size: 56px; }   /* 增大分数显示 */
.card-name { font-size: 15px; }   /* 增大卡片文字 */
```

## 📊 数据存储

### 存储位置
所有数据保存在浏览器的 LocalStorage 中：
- `kidsCards` - 卡片列表
- `kidsScore` - 总积分
- `kidsHistory` - 历史记录

### 数据备份
目前数据存储在本地，建议：
1. 定期截图保存记录
2. 不要清除浏览器数据
3. 未来版本可以添加云同步功能

### 清除数据
如果需要重置：
1. 打开浏览器开发者工具（F12）
2. 进入 Application > Local Storage
3. 删除相关项目
4. 或者直接清除浏览器缓存
